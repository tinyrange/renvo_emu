# Register coverage manifests

These six manifests are generated by `scripts/generate-register-coverage.sh`
from the bus logs and run results produced by `scripts/docker-smoke.sh`.
Every listed register is therefore an address actually accessed by passing,
Docker-built firmware. Each proof records SHA-256 hashes for both its run result
and full bus log.

Coverage is evidence, not an assertion that unlisted registers are unsupported.
Conversely, mapping a register is not enough to list it here: a passing proof
must access it. The `known_deviations` entries state the deliberate functional
limits of each chip model. The generator fails if any required chip-facing
region disappears from the tested coverage.

Regenerate the manifests with:

```sh
scripts/docker-smoke.sh
```
